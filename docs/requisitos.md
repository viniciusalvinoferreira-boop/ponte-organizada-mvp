# Requisitos do MVP

## Requisitos funcionais

| ID | Descrição |
|----|-----------|
| RF01 | Autenticar usuários da equipe por email e senha |
| RF02 | Cadastrar aluno ou associado com nome, data de nascimento, telefone e tipo de vínculo |
| RF03 | Impedir cadastro duplicado de aluno e avisar a equipe |
| RF04 | Registrar e consultar a situação do associado (ativo ou pendente) |
| RF05 | Manter fila de espera por projeto, ordenada por data e hora de entrada |
| RF06 | Montar grupos de um projeto a partir da fila, respeitando o número de vagas |
| RF07 | Impedir seleção de aluno com situação pendente |
| RF08 | Controlar o acesso por perfil (equipe e voluntário) |

## Requisitos não funcionais

| ID | Descrição |
|----|-----------|
| RNF01 | Aplicação web responsiva, usável em celular |
| RNF02 | Acessibilidade: contraste adequado, foco visível e rótulos em todos os campos |
| RNF03 | Mensagens de erro claras, com indicação de como corrigir |
| RNF04 | Interface simples, pensada para equipe sem familiaridade com sistemas |

## Fora do escopo

Doações, aplicativo nativo e integrações externas.
